# SinglePageApplication

This is the repository for my Single Page Application for COMP 1004.
As of 17/11/26, I am planning to create an incremental rocket launching game, akin to Learn To Fly 3. 

The essence of this project is an entertaining incremental game, in which the player will repeatedly launch rockets that get more and more powerful via upgrades and swapping parts out, in order to get higher and higher and eventually reach the moon. The player will be able to upgrade the engine, body, fins, and cockpit of the rocket. These will relate to different stats for the rocket: power, fuel, drag, and control, respectively. Power means more thrust but more weight, fuel means increased weight but longer burn, drag means that the air resistance is less, and control lets the player turn the rocket faster to avoid obstacles. These obstacles will be stuff like planes, balloons, kites, blimps, and in space there will be asteroids and satellites to avoid. Hitting these slows the rocket down, which is bad for getting to the moon. 

The general gameplay loop will look like this: player launches rocket and gets as high as they can. Once they start to descend, the run ends and they earn coins/money for how high they got plus airtime. Upon collecting the money, they visit the R&D lab where they can purchase upgrades for the rocket. Then when they are ready, they can launch the rocket again for more money. The main goal is to get to the moon at an arbitrary height. 

The main inspiration for this project is a game called Learn To Fly 3, where a penguin continuously launches itself into space in order to learn how to fly. https://store.steampowered.com/app/589870/Learn_to_Fly_3/

I will also want to research how to implement physics into a webpage application, as well as flipping through menus with a main menu, setting menu, game screen, and the shop.
